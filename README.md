# 🚀 Deploy Your Streamlit App

## 🎯 Objective

Copy the provided project into **your own GitHub repository** and deploy it using **Streamlit Community Cloud**.

## 📋 Steps

### 1. Create Your Own Repository

* Create a **copy of the provided project**.
* Create a new repository under **your own GitHub account**.
* Upload/push the project files to your repository.

### 2. Deploy on Streamlit

1. Go to [Streamlit Community Cloud](https://streamlit.io/?utm_source=chatgpt.com).
2. Sign in using your **GitHub account**.
3. Create a new app.
4. Select **your GitHub repository**.
5. Select the branch containing your project.
6. Set the main file to:
   `streamlit_app.py`
7. Click **Deploy**.

### ✅ Expected Result

Your application should be successfully deployed and accessible through a **public Streamlit URL**.

### 📌 Submission

Submit:

* Your **GitHub repository link**
* Your **deployed Streamlit application link**
